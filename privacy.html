Backup Service — частное приложение, которое с разрешения владельца аккаунта работает с его Google Drive для хранения резервных копий.

Приложение может загружать файлы в Google Drive, получать список сохранённых файлов и удалять устаревшие копии. Доступ используется только для выполнения этих операций.

Файлы хранятся в Google Drive владельца аккаунта. Приложение не передаёт полученные через Google API данные третьим лицам и не использует их для рекламы.

Владелец аккаунта может отозвать доступ приложения в настройках своего аккаунта Google.
